What it is

Claude Code configuration lives in a dozen kinds of files. AgentDock puts it on one canvas.

It reads the files Claude Code already uses, such as .claude/, .mcp.json and CLAUDE.md, so there is no new format to adopt. AgentDock edits configuration. It never runs your agents.

AgentsSkillsCommandsRulesCLAUDE.mdSettingsHooksOutput stylesMCP serversPluginsMemory

See the relationships

Select an agent and its skills light up. Drag a skill onto an agent to connect them. Missing and broken references show up on the canvas, not in a stack trace.

Edit in place

Change frontmatter, tool lists and instructions from one inspector. The raw markdown or JSON is always one tab away, with syntax highlighting.

Review before you save

Validation lists errors, warnings and notes with a jump to the resource. Every edit appears as a diff, and nothing reaches disk until you save.
